# Crazy Collab

> Create meeting times that work for everyone.

CrazyCollab is a web application that helps groups plan meetings based on overlapping availability in schedules. Individuals in a group can either remotely or locally input their available dates and times, adapting across timezones, and cross reference availability with other group members. From there, a group meeting can be scheduled and sent to google calendar for easier tracking and planning.

## Features:

- **Easy to Navigate and Accessible UI** with a high contrast color palette
- **Quickly establish meetings** with other group members
- **Schedule overlap shown with darker colors**, easily visualizing schedules in one place
- **Google Calendar Event Creation** and account syncing
- **Saved User Login System** and account creation system
- **Compatibility across different time zones** allows users from different areas to collaborate

## Quick Start

```bash
git clone https://github.com/sarahpilon/CrazyCollab.git
cd CrazyCollab
# Fill in Google API secret in a .env file in base folder
# Install packages
npm run dev
```

See the [Setup manual](Setup.md) for full setup instructions.
