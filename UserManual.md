# User Manual

Our product is a web application that helps groups plan meetings based on overlapping availability in schedules. Individuals in a group, either remotely or locally, can input their available dates and times, adapting across timezones, and cross reference availability with other group members. From there, a group meeting/event can be scheduled and sent to google calendar for easier tracking and planning. ([Referenced from ReadMe.md](https://github.com/sarahpilon/CrazyCollab/blob/main/README.md#abstract))

# How to Use

## Getting Started

When you first visit the site, you will be prompted to either Log In, Sign up, or continue as a Guest. After choosing the suitable option, you will see a calendar on the right side of the screen to select your availability. On the left side of that same screen, you will see an option to join or create a group. The instructions on how to navigate each part is as follows: 

- **Join a Group (left side):**  
1. User will select the Join a Group option  
2. They will then be prompted to accept an invitation if they have any  
3. If user does not have any, a message will be displayed indicating so  
4. Once a user joins the group, all other members who have accepted an invites availability will pop up  
5. Continue onto **Scheduling Meeting**  
- **Create a Group (left side):**  
1. User will be prompted to invite group members   
2. User must name the group meeting  
3. Continue onto **Scheduling Meeting**  
- **Setting Availability (right side):**  
1. Navigate to the right side of the screen to the calendar  
2. Underneath “Set your availability timezone”  
3. In the calendar UI, click and drag to select times you are unavailable, and the timeframe you are adding in the periods.  
4. Continue to **Join a group** or **Create a Group**

## Scheduling Meeting

1. Users will be asked to input an already set schedule (the one made in the homescreen), or input a whole new one.  
2. **IF the user is a host,** they can click on save meeting  
3. Suggested meeting times will pop up**,** or the user can select a meeting time **if they are the host**  
4. From there anyone can press export, and a calendar event will be added to their calendar  
5. If a user in the group was not logged in, they will be prompted to log in or add in their email to send the calendar event to. 

# Bug Handling

A full list of our bugs can be found in our [issues tracker](https://github.com/sarahpilon/CrazyCollab/issues). As we are still developing our program, some features may be incomplete or contain bugs, so please be wary of that. 

**Before Reporting a Bug:**

1. Make sure that your system is up to date  
2. Make sure your web browser is up to date  
3. Make sure your environment is within the requirements (not on microsoft edge, or firefox)  
4. Check in existing bugs to see if it already exists and is documented

**How to report a bug:**

To report a bug follow the steps below:

1. Navigate to the [issues tab](https://github.com/sarahpilon/CrazyCollab/issues) next to code  
2. Click the new issue button  
3. Click on Bug Report  
4. Fill out the documentation as instructed\!
